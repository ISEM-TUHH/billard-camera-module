Camera calibration

This page guides you through the camera calibration process. We assume that the lens distortion has already been configured as per installation (see README > Calibration > Lens Correction on GitHub). This page has the same information as the chapter on Image cropping.
Important: by clicking on the link that brough you here, you have already activated the calibration process. The camera is already looking for the markers. If it finds the markers in the wrong positions/arangement, the output will look bad. To restart the process, just reload this page.
The implementation searching for markers is very unoptimised, so you may see significantly lower FPS in the livestream.

1. Have the ArUco markers ready

They look like QR codes and are glued onto wooden panels (see image below). Sources providing the markers are given in the README linked above (or directly here)

2. Place the markers in the corners

On every marker the corresponding corners should be noted. Place the marker in the corner, such that it aligns like the image shows.
The marker order is (1, 2, 3, 4) top-left, top-right, bottom-left, bottom-right.

3. Wait for the camera to pick them up

If the camera does not quickly (10s) pick up the marker positions, check if the camera can see the markers. Detected markers are shown with a colored rectangle in the livestream. Other troubleshooting steps are:
  • With a manual focus camera, check all corners are in focus
  • Change the lighting
  • Consider printing larger markers

4. Save the calibration

If you are happy with the calibration results, go to /v1/savetransformation to it. Whenever the camera restarts, this will be loaded.
