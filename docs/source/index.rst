Camera Module - Billard@ISEM documentation
========================================

The Camera Module is a part of the Billard@ISEM system, ultimately aiming at teaching students relevant mechanical design principles as well as provide a research environment for agile product development methods. The Camera Module provides a livestream and has the ability to detect the ball position and type using YOLO models. It runs on the Nvidia Jetson platform.
